
Тема ВКР:
Разработка онлайн-эмулятора языка ассемблера для поддержки учебного процесса в вузе

1.1. Тип ВКР - Исследовательская работа.

1.2. Цель исследования – сокращение трудозатрат по настройке и эксплуатации учебного программного обеспечения при использовании в учебном процессе в вузе.

1.3. Объект исследования - процесс взаимодействия обучаемых с учебным программным обеспечением.

1.4. Предмет исследования - возможность сокращения трудозатрат по настройке и эксплуатации учебного программного обеспечения при использовании в учебном процессе в вузе.

1.5. Методы исследования – семантический анализ, теория баз данных, эргономичность и юзабилити (удобство использования).

1.6.1. Провести анализ процесса взаимодействия обучаемых во ФГАОУ ВО "МГТУ "Станкин" с учебным программным обеспечением при изучении языка ассемблера.

1.6.2. Провести обзор альтернативных вариантов учебного программного обеспечения для изучения языка ассемблера, выявить их достоинства и недостатки, обосновать необходимость разработки собственного онлайн-эмулятора.

1.6.3. Сформулировать требования к разрабатываемому онлайн-эмулятора языка ассемблера.

1.6.4. Реализовать макетный вариант онлайн-эмулятора языка ассемблера для поддержки учебного процесса в вузе.
